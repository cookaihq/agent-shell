# 任务自动化

## 入口：rail「任务自动化」

左侧 rail 第四项（看板三列矩形图标），悬停提示「任务自动化」，点击打开独立面板。页面分两大区：**「你的自动化」**（任务列表 + 筛选）和**「模板」**（快速新建模板卡片）。

---

## 功能概述

任务自动化让 agent 在**触发器到点或手动触发**时，在后台无人值守跑一条任务，产出留成可回看的会话与运行历史。每个任务的「定义」存成一个磁盘文件夹（`AUTOMATION.md`），可分享、可自带脚本/参考资料。

两种执行方式：
- **Agent 执行**（默认）：到点喂引擎跑一段提示词（需推理的任务）。
- **脚本直跑**：到点直接跑脚本、不经 LLM（确定性任务，如扫描/比对，省钱省时）。

---

## 新建 / 编辑任务 = 交给 agent（agent-led）

**新建和「编辑内容」不再是填表，而是交给 agent 帮你建/改**：

- 点右上角「**新建自动化**」→ app 把一段「我想建个定时任务，请帮我确认这些信息…」的提示词**塞进首页输入框**，你按发送，agent 在会话里和你确认（要做什么、什么时候触发、用哪个引擎/权限、归哪个分类、要不要密钥），齐了就用 **`create_automation` 工具**把任务写进库。
- 点卡片「**编辑**」→ 同样塞首页一段「帮我改任务『X』的内容」，agent 读出当前指令、按你的要求改，再用工具更新。
- 点模板卡片 → 把模板内容组装成提示词塞首页，agent 据此帮你建。

> agent 用的工具叫 `create_automation`（列表里可能带 `mcp__…__` 前缀）。它会**校验参数后写库**，不让 agent 直接乱写磁盘。app 自带一个内置技能「create-automation」教 agent 怎么用它——普通会话里注入该技能后即可让 agent 帮你建任务。

---

## 卡片「设置」弹窗 = 改结构化字段（不改内容）

点卡片「**设置**」（齿轮图标）打开设置弹窗。它**只设结构化字段**，标题和提示词（任务做什么）是只读的——**要改内容请用「编辑」交给 agent**。弹窗底部是若干可点击 pill（点开浮层配置，点空白/Esc 收起）：

- **引擎 · 模型 · 权限档**（三合一）：引擎 Claude/Codex；模型（Claude: Opus/Sonnet/Haiku；Codex: GPT-5.5）；权限档无人值守时生效（Claude 5 档 default/acceptEdits/plan/auto/bypassPermissions；Codex 3 档 read-only/workspace-write/danger-full-access），选最宽档有风险提示。
- **触发器**（可挂多个）：见下「触发器」。
- **执行方式**：Agent 执行 / 脚本直跑（选脚本时填脚本入口，如 `scan.mjs`）。
- **目标项目**：每次新建项目（默认）/ 复用某已有项目（可搜索）。
- **分类**：层级树**单选**（见下「分类 vs 标签」），含「管理分类…」入口。
- **标签**：扁平**多选**，可回车新增。
- **配置（密钥）**：见下「配置 / 密钥绑定」。

点「**保存设置**」提交。

### 触发器（列表 · 可多个）

一个任务可挂多个触发器，到任一触发点都会跑：
- **启动触发**：daemon 启动时触发一次。
- **每小时**：每小时第 N 分。
- **每天 / 工作日 / 每周**：指定时间（HH:MM）+ 时区（上海/UTC/纽约/东京）；每周还要选星期几。

在触发器 pill 里用「+ 启动触发」加启动触发，或选频率/时间/时区后「添加该触发器」加时间触发；每条可单独删除。卡片上多个触发器的摘要用「·」拼接（如「启动时 · 每天 09:00 · 上海」）。

### 分类（层级·单归属） vs 标签（扁平·多选）

- **分类**是层级树、**单归属**（一个任务只属一条分类路径，如「运营 ▸ 监控」），是主组织维度。在「设置」的分类 pill 或任务页筛选区点「**管理分类…**」打开**管理分类模态**：树形增删改（加子分类 / 重命名 / 删除 / 加顶级分类），改动即落库。
- **标签**是扁平、**多选**、横切（如「紧急」「实验性」），用于跨分类筛选。

### 配置 / 密钥绑定

若任务运行需要环境变量（密钥），任务定义里会**声明**这些 env（`requires`）。设置弹窗的配置区列出每个声明的 env + 一个绑定下拉（绑到本机**命名密钥**，或新建密钥）+ 「已绑定 / 未绑定」标志。**声明由 agent 写、绑定由你做**——绑哪个密钥是你的动作，不会替你绑。

## 任务列表与卡片

列表顶部显示「启用 / 暂停」计数 + 右上角「新建自动化」。每条卡片显示：分类面包屑、任务名、配置标志（有声明 env 时：需配置 / 已配置）、触发器摘要 · 目标 · 权限 · 上次状态 · 下次时间（或「已暂停」）、标签 chips。

卡片操作：

| 操作 | 说明 |
|------|------|
| 运行 | 立即手动触发一次，不影响定时 |
| 历史 | 打开该任务运行历史抽屉 |
| 编辑 | agent-led 改内容（塞首页交给 agent） |
| 设置 | 打开设置弹窗改结构化字段 |
| 暂停 / 启用 | 切换启用状态；暂停后定时不触发 |
| 删除 | 确认后永久删除 |

## 筛选

- **分类筛选（层级 drill）**：点分类钻入下一级（面包屑可回退），只看该分类及其子类下的任务。
- **标签筛选（多选 AND）**：点标签 chip 多选，只看**同时**带所有所选标签的任务。
- 两者**叠加**（分类 AND 标签）。

---

## 运行历史

点卡片「历史」打开抽屉，列出每次运行：开始时间、触发方式（定时/手动）、状态（6 种：排队中/运行中/已完成/失败/待复核/已取消，颜色标注）、耗时、错误或摘要、「打开会话」链接（agent 执行的任务有会话；脚本任务无会话）。

---

## 模板

「你的自动化」下方是模板区（卡片网格）。点模板「使用模板 ›」走 **agent-led**：把模板内容组装成提示词塞首页，agent 帮你确认并落地。模板区支持按分类筛选。

---

## 后台常驻与关窗行为

**关窗不退**：关闭应用窗口后，app 缩到系统菜单栏托盘继续运行，定时调度器保持存活，到点照常触发任务。

**重新打开窗口**：关窗后想再开窗口，点系统菜单栏的托盘图标选「打开 Agent Shell」，或直接点 Dock 里的应用图标——都会重建窗口（后台进程一直没退，秒开）。

**真正退出**：仅通过托盘菜单的「退出」选项，或 Cmd+Q 退出应用，才会真正停止后台进程和调度器。

这一机制保证定时任务不会因关窗而中断。
