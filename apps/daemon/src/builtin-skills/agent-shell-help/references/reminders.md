# 提醒与通知

## 提醒能做什么

AgentShell 可在三个关键时机推送提醒：

| 事件 | 触发时机 |
|------|---------|
| **需授权（attention）** | agent 在等待用户回答或批准操作时 |
| **完成（complete）** | 一轮任务成功跑完时 |
| **失败（failed）** | agent 报错、超时或崩溃时 |

每个事件可以独立配置渠道和音效。

---

## 提醒渠道

三种渠道可组合使用：

| 渠道 | 说明 | 失焦限制 |
|------|------|---------|
| **应用内通知（inapp）** | 应用内弹出通知，显示在右上角通知中心 | 不限，窗口在前台也触发 |
| **声音（audio）** | 播放提示音 | 仅在 app 窗口失焦时触发 |
| **系统通知（system）** | macOS 系统通知中心弹窗 | 仅在 app 窗口失焦时触发 |

---

## 在哪配置

提醒配置有两个入口，分别作用于不同范围：

### 项目级配置（优先级高）

**项目设置菜单 › 项目提醒设置**：针对当前项目单独设置，会覆盖全局默认值。配置落到项目目录的 `.agent-shell/reminders.json`。也可以直接让 Agent 帮你改这个文件（见「对话式配置」一节）。

### 全局默认配置

**设置 › 提醒**：全局默认值，新建项目时会拷进项目作为初始配置；已有项目不受影响。

全局默认页比项目级少两块（因为全局没有具体项目可落盘）：
- **音频只支持系统预设**（default/crisp/alert/chime）+ 试听，**不能上传**自定义音效（上传文件要存进某个项目的 `.agent-shell/sounds/`）。
- **外部渠道只有开关**，不在这里填 Webhook 地址 / 飞书签名等连接信息——连接信息请到各项目的提醒设置里配置。

该页用显式「保存」按钮提交（改完点保存才落库）。

### 通知中心

**右上角铃铛图标**：打开通知中心，查看历史提醒记录；铃铛上的红点表示有未读通知。点面板里任意一条会跳到对应项目/会话；点「全部已读」清空列表并灭红点；点单条的 × 删该条。

**瞬时卡片**：有应用内提醒时，右上角会浮出一张卡片——「需授权」常驻直到手动关闭，「完成/失败」约 5 秒自动消失。点卡片同样跳到对应会话。点 macOS 系统通知则会聚焦窗口并跳到对应会话。

## 音频系统

音效的选择、试听、上传都在提醒配置弹窗里完成：当某事件开了「声音」渠道，下方会展开音频选择区。

### 系统预设音效

四个内置音效：`default`（默认提示音）、`crisp`（清脆）、`alert`（警示）、`chime`（悦耳钟声）。每行旁的 ▶ 可试听。系统音频默认收起，点「展开」看全部。

### 上传自定义音效

在音频选择区的「已上传」一栏点「上传…」选本地音频文件（支持常见格式），上传后自动选中，并可点文件名就地改个好记的展示名。每行旁的 ▶ 同样可试听。上传的文件存在项目 `.agent-shell/sounds/` 下。

---

## 外部渠道（webhook / 飞书）

在提醒配置弹窗顶部的「外部渠道」tab 里，可启用 Webhook 或飞书两种外部渠道：打开对应开关后展开输入框，填连接信息（Webhook 填 URL；飞书填机器人 Webhook 地址 + 可选签名密钥）。

**连接信息自动进密钥库**：你填的 URL、签名密钥**不会明文写进项目文件**——保存时会自动存入密钥库，项目配置里只留一个引用（secretRef）。所以项目目录分享出去也不会泄露这些信息；再次打开弹窗时只显示「已配置」，不回显明文（要改就重填覆盖）。这些密钥也会出现在「设置 › 密钥管理」的列表里。

---

## 对话式配置（让 Agent 改 reminders.json）

在对话里直接告诉 Agent 想改哪个事件的提醒方式，Agent 会读写项目根目录下的 `.agent-shell/reminders.json` 来应用配置。改完实时生效，无需重开会话。

例：
- 「任务完成时也给我播声音」→ 把 `events.complete.channels` 加上 `"audio"`
- 「失败时用警报音」→ 把 `events.failed.sound.id` 改成 `"alert"`
- 「关掉所有提醒」→ 把顶层 `enabled` 设为 `false`
