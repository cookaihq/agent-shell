# 命令行工具（CLI Tools）

AgentShell 能把本机的命令行工具（如 ffmpeg、jq、pandoc 等）接给内置 agent 用。入口在「集成 › 命令行工具」。

## 检测即可见（不用「加入」）

打开「集成 › 命令行工具」，AgentShell 会**自动检测本机已装的工具**：

- **已安装**区：本机检测到的工具（显示版本号），agent 可直接调用，无需任何手动「加入」操作。
- **可安装**区：内置目录里**还没装、且支持当前系统**的工具，每个带「安装」按钮。不支持当前系统的工具不会出现在这里。

> 旧版的「加入 / 订阅」概念已取消——工具是否对 agent 可见，只取决于本机是否检测到它已安装。

## 安装：交给 agent 做

点某个工具的「安装」按钮，AgentShell **不会在应用内直接执行安装**，而是：

1. 把这条安装请求**组装成一句提示词**，预填进**首页输入框**并跳到首页；
2. 你确认后**发送**，由 **agent 实际执行安装**（agent 会按当前系统选对安装方式、跑完、并登记用途）。

这样授权、报错处理、写用途说明都在 agent 手里，与 AgentShell「让 agent 做事」一致。

## 登记自定义工具（按绝对路径）

本机已装、但不在内置目录里的工具，可在该页**按可执行文件的绝对路径登记**进来（填路径 + 可选名称 / 用途说明），登记后同样对 agent 可见。

## agent 怎么管 CLI 工具

在对话里直接让 agent「装个 jq」「看看有哪些命令行工具」「更新 xxx」，agent 会用内置的 `as_cli_*` 工具（列目录 / 安装 / 登记 / 查更新 / 更新）来做，而不是自己瞎跑 shell 安装脚本。已装工具还会被注入 agent 的系统提示，让它知道本机有哪些工具可用。

> 注：`as_cli_*` 这套工具目前仅 **Claude 引擎**的会话可用；Codex 会话里 agent 会改用其它方式或提示无法。
