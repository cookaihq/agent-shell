# 项目、工作区、中断与继续

## 建项目

### 入口一：rail「新建项目（+）」或顶部页签「+」

点击这两个入口都会弹出「新建项目」弹窗，弹窗字段：

- **项目名称**：自由输入，留空提交默认填「未命名项目」。
- **存储位置**：只读展示，显示从系统设置读来的父级目录（默认 `~/AgentShell/projects`）。实际项目目录名由系统自动生成（非显示名），父级目录只能在「设置 › 系统设置」里改，弹窗内不可改。

点「创建项目」后直接进入该项目的工作区。

### 入口二：首页输入框直接发送

在首页（工作区）的大输入框里写描述，回车或点发送箭头，即触发「建新项目 + 立即跑第一条会话」，无需先弹新建弹窗。首页输入框支持：

- 直接输入文字描述任务
- 回形针按钮选择本地文件/文件夹作为附件
- 粘贴剪贴板图片
- 点「注入技能」选择要随本次会话注入的技能（仅本机 CLI 下显示）

## 项目列表

在 rail 点「项目」进入项目列表页，可以：

- **网格 / 看板** 两种视图（右上角切换），看板按项目状态分列。
- **搜索**：输入关键词过滤项目名称。
- **排序**：左侧下拉选择排序依据。
- **重命名**：在卡片菜单（⋯）里选「重命名」，弹就地编辑框。
- **删除**：在卡片菜单选「删除」，弹二次确认；同时删除磁盘文件，不可撤销。
- **批量删除**（仅网格视图）：点「选择」进入多选态，勾选后删除所选。

首页（工作区）的「最近项目」区也会展示最多 4 个最近项目卡，点击直接进入工作区。

## 工作区怎么用

进入项目后进入工作区，分三个区域。

### proj-bar（顶部项目条）

工作区顶部条，从左到右：

- **返回按钮**：退出工作区，回到上一页面。
- **引擎色点 + 项目名**：项目名可点击，点击后就地编辑重命名，回车保存，Esc 取消。颜色点（engdot）**只读**，反映**当前会话**的真实引擎（claude 橙色 / codex 蓝色）。
- **runtime chip（RuntimeSwitcher）**：位于 proj-bar 右侧，点击弹出档位/思考强度/模型联动的切换面板，配置生效范围为当前会话。档位随引擎不同：Claude 是单一「权限档」（5 档），Codex 是两轴——「沙箱」（只读 / 工作区可写 / 完全访问）+「审批」（每次问 / 按需问 / 从不问）。chip 里的「代理」格还能切换会话的 Agent（引擎），行为见下。
  - **Claude 权限档切换的生效时机**：默认 / 接受编辑 / 计划 / 不询问 这几档之间切换，对正在进行的回合即时生效（影响之后的工具调用）。唯独切到「**绕过**」会在**下一条消息**才真正生效——绕过依赖底层进程启动时才能开启的开关，切换时外壳会在下一轮沿用会话上下文重起进程来拿到它（历史对话不丢失）；因此当前回合里已经弹出的授权卡仍需你处理，绕过从下一条消息起才静默放行。想一开始就静默绕过，最稳的是**发会话第一条消息前**就把档位选成「绕过」。

#### Agent（引擎）是会话的属性

Agent（Claude / Codex）挂在**会话**上——每条会话有自己的引擎，同一项目下不同会话可以用不同引擎。在 runtime chip 的「代理」格里切换 Agent 时，按当前会话是否已发过消息分两种行为：

- **未发送的会话**（新建后还没发第一条消息）→ **原地变身**：当前会话直接切换到新引擎，色点、档位（权限 / 沙箱 / 审批 / 思考强度 / 模型）都随之变成新引擎的，不新开会话。
- **已发送过消息的会话** → **不动当前会话**：当前会话保持原引擎继续（色点不变），切换只把**项目「下个新会话用哪个引擎」**改成新选择。此时 proj-bar 会显示「下个新会话用 {引擎名}」标记提示；要用新引擎，点聊天区「+」新建一条会话即可（不会自动开、也不弹提示）。

新建会话默认用**项目记住的「选中 Agent」**——这是项目级、持久化的：重开项目、重启 app 都记得上次选的引擎。

### 左栏：聊天区

**会话 tab 条**（顶部横向 tab）

当前项目下所有已打开的会话排成 tab，支持点击切换。tab 上的彩色圆点反映状态（运行中脉冲 / 失败恒显 / 完成·空闲时未读才显）。可点 × 关闭某个 tab（仅关标签，不删会话记录）。

**历史会话弹窗**

点聊天区顶部的历史图标（时钟图标）弹出历史会话弹窗，可：

- 搜索本项目内的会话。
- 按「普通会话 / 自动化」两个 tab 分别查看（自动化 tab 展示定时任务产出的会话）。
- 对每条历史会话：点标题切换到该会话；点置顶图标置顶/取消置顶；点编辑图标重命名；点删除图标（垃圾桶）进二次确认后真删（含对话历史，不可恢复）。
- 对失败或已中止的会话：显示「继续（▶）」按钮，点击可恢复该会话运行。

**新会话**：点聊天区顶部的「+」按钮新建一条会话。

**聊天内容**

会话消息时间线展示：

- 用户气泡（含附件 chip，点击可在右侧预览区打开）
- 助手回复（prose 流式文字、思考折叠块、工具卡）
- 工具卡三种：文件读取 / 运行命令 / 编辑（含行级 diff）
- 任务计划 todo 卡
- **子代理（并行代理）**：当主代理派生子代理时，时间线里就地出现一个子代理组块——每个子代理一行（任务标签 + 状态点 + 可展开的内部迷你时间线 + 完成后的「汇报」）。Codex 引擎下还会显示并发导轨与「主代理等待中」徽章（主代理在等子代理时）。聊天区顶部也会出现头像入口（Claude 为字母头像、Codex 为 ⬢ 堆叠，每个并发子代理一个），点击可切到右栏的子代理面板。
- 失败或中止时，末尾显示状态条（「已中止当前任务·已完成内容已保留」或「任务失败·原因」）并附「继续」按钮

### 左栏：composer（输入区）

位于聊天区底部，功能：

- **文本输入框**：输入消息，Enter 发送，Shift+Enter 换行。
- **@ 引用文件/技能**：输入框里打 `@` 触发提及面板，可选择项目内文件路径或技能名称注入引用。
- **/ 斜杠命令**：输入框里打 `/` 触发命令面板，列出当前项目/会话可用的斜杠命令，点击或键盘选择后插入命令文本。
- **附件**：回形针按钮打开原生选择器，可选文件/文件夹；也可直接粘贴图片。附件以 chip 形式显示，可逐个移除。
- **ModelPill（模型胶囊）**：展示当前模型 + 档位简称 + 思考强度（Effort），点击弹出配置面板，随引擎动态变化——Claude 配「权限档 / Effort / 模型」，Codex 配「沙箱 / 审批 / Effort / 模型」（两轴权限）。
- **当前打开文件（CtxFile）**：若右侧已打开某文件，会在 composer 底部显示该文件 chip；发送消息时会把该文件路径作为「当前文件」自动告知 AI（仅路径、不含内容），点该 chip 可把它移出上下文（再点加回）。
- **上下文计量环（CtxMeter）**：显示本会话已用 token 数和费用（有成本数据时显示），运行中实时更新。
- **发送/停止键**：任务运行时变为停止键（■），点击中断当前任务；空闲时为发送键。

### 右栏：文件工作区

右侧面板，包含：

- **「文件」固定 tab**：显示项目目录树和文件列表，可展开/收起目录。
- **用本机编辑器打开项目**：目录树「资源管理器」标题旁有一个下拉箭头，点开列出本机检测到的编辑器（如 VS Code、Cursor、Finder、终端等；已安装可点，未安装灰显）。选一个即用它打开**当前项目根目录**。这是「纯打开」——不设默认编辑器，每次都从列表选。仅桌面应用内可用。
- **可关闭文件 tab**：打开文件后在 tab 条新增该文件 tab，可 × 关闭。
- **视图切换**：目前仅「预览」视图（Diff / Git 视图为后续版本计划）。
- **预览面板**：文件预览及命令输出预览。
- **子代理面板**：当本会话有子代理时，tab 条出现「子代理」tab（带数量）。Claude 为 Gallery/Board 两种排布的卡片，每个子代理一张卡（任务 + 内部时间线 + 状态）；Codex 为并发流看板（Board），每个并发子代理一列（任务标签 + 完整实时迷你时间线 + 汇报 + 状态），列头标注运行中/已完成，主代理等待时显示「主代理等待中」徽章。无子代理时不显示该 tab。
- **拖拽放置**：可从系统文件管理器拖文件/文件夹进右侧面板，作为附件或导入项目。

## 中断与继续

### 中断当前任务

任务运行中，composer 底部的发送键变为**停止键（■）**，点击后：

- agent 子进程收到中止信号。
- 当前会话状态变为「已中止」。
- 聊天区末尾显示状态条「已中止当前任务 · 已完成的内容已保留」，并附「继续」按钮。

### 继续一个会话（三个入口）

1. **状态条上的「继续」按钮**：中断或失败后，聊天末尾状态条上的继续按钮，点击立即恢复当前会话运行。
2. **历史会话弹窗里的「▶ 继续」**：点历史图标打开历史弹窗，找到失败或已中止的会话，点右侧的继续图标（▶）切换到该会话并触发继续。
3. **会话 tab 条未激活的 tab**：点未激活 tab 切换到对应会话，再用以上按钮继续。

继续操作发出后，聊天区立即乐观渲染一条「继续」用户气泡，会话切回运行态；如果继续请求失败（网络或服务异常），会在末尾显示失败原因。

### 会话状态说明

历史会话弹窗中每条会话显示当前状态，状态含义：

| 状态 | 含义 |
|------|------|
| 运行中 | 当前正在执行 |
| 已完成 | 正常跑完 |
| 失败 | 出错中止 |
| 已中止 | 用户手动中断 |
| 未开始 | 新建但未发过消息 |

自动化任务产出的会话额外有「待复核」状态（任务执行后需人工查看）。
