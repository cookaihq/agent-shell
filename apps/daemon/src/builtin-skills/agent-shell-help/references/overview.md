# AgentShell 总览

## AgentShell 是什么

AgentShell 是一个**本地优先的桌面客户端**，集成 Claude Code、Codex 两个编码 agent 引擎，用统一的图形界面驱动多个 agent 会话。工作内容按「项目」组织，每个项目对应本机的一个目录。

AgentShell **不是**云端服务，本身也不内置大模型——它通过这两个引擎调用上游模型，默认复用你本机 CLI 的登录态（你在终端登录过的那个账号），无需额外配置；也可在「设置 › 执行模式」里为某个引擎配置自定义 Provider（上游 / 中转站），详见 providers.md。

## 支持的引擎

V1 支持两个引擎：

- **Claude Code**（`claude`）
- **Codex CLI**（`codex`）

在「设置 › 执行模式」可以看到两个引擎的检测状态和版本，并对每个引擎做连通性「测试」；某个引擎不可用时，其卡片会灰显不可选。

引擎（Agent）是**会话级**属性：每条会话用一个引擎，同一项目下不同会话可混用；新建会话默认用项目记住的「选中 Agent」（持久化）。在工作区 proj-bar 切换 Agent 时，未发送的会话会原地变身、已发送的会话只改下次新建默认——详见 projects.md「Agent（引擎）是会话的属性」。

## 整体导航结构

### rail（左侧导航栏）

界面左侧的垂直导航栏称为 **rail**，包含以下入口（从上到下）：

| 入口 | 功能 |
|------|------|
| **新建项目（+）** | 弹出「新建项目」弹窗，填写项目名称和存储位置 |
| **工作区** | 返回首页（home），显示输入框和最近项目列表 |
| **项目** | 打开项目列表页，查看所有已建项目 |
| **任务自动化** | 打开任务自动化页，管理定时/手动触发的后台任务 |
| **集成** | 打开集成页，管理技能库及其他集成配置 |

rail 底部另有「帮助」按钮（当前为占位）。

### 顶部页签（chrome）

应用顶部是页签栏，类似浏览器标签页。每打开一个项目会新增一个页签，入口页（工作区/项目/任务自动化/集成）各有一个单例页签。点击页签可在多个项目间切换，也可点「+」新开标签（回到工作区首页）。

### 设置

设置以弹窗形式打开（按 Esc 或点击遮罩关闭），包含四个子页：

- **执行模式**：查看已检测到的 CLI 引擎（Claude / Codex）、版本与内置模型列表，对每个引擎做连通性「测试」；为某引擎配置自定义 Provider / 登录来源（详见 providers.md）。Codex 卡片还会显示协议兼容徽标（✓ 已适配 / ⚠️ 未测试版本——app-server 协议是实验性的，仅对测过的确切版本标已适配，非硬阻断）。
- **系统设置**：修改项目默认存储目录（默认 `~/AgentShell/projects`）和技能库目录（默认 `~/.agent-shell/skills`）。
- **密钥管理**：管理技能所需的命名密钥（增删查，供技能配置绑定）。
- **代理**：管理代理池（增删改 + 测试连通/延迟）；池里的代理可在「执行模式」里被某个登录来源 / 自定义 Provider 绑定使用，详见 providers.md。

### 集成页

「集成」页包含 5 个 tab：

- **技能**（当前可用）：技能库清单，支持添加来源（Git 仓库 / 本地文件夹）、搜索、删除、对 Git 来源执行更新。
- **MCP / 连接器 / 远程桥接 / 数据同步**：四个「即将上线」占位，功能尚未开放。

## 快速指路

| 想做的事 | 去哪里 |
|----------|--------|
| 开始一个新编码任务 | rail「新建项目（+）」或工作区首页直接输入发送（发送即建新项目） |
| 查看和切换已有项目 | rail「项目」，或顶部页签直接点击 |
| 管理技能（添加/更新/删除来源） | rail「集成」›「技能」tab |
| 设置定时或手动后台任务 | rail「任务自动化」 |
| 切换引擎或查看 CLI 检测状态 | 设置 ›「执行模式」 |
| 修改项目默认存放目录 | 设置 ›「系统设置」 |
| 管理技能密钥 | 设置 ›「密钥管理」 |
| 管理代理 / 给某个上游来源绑定代理 | 设置 ›「代理」（建代理）+「执行模式」（在来源行选代理） |
